## 2. 技术栈

- **UI 框架**：ArkUI（声明式，@Entry/@Component + build() 语法）
- **应用模型**：Stage 模型，单 Ability（UIAbility）
- **日志**：@kit.PerformanceAnalysisKit（hilog，DOMAIN=0x0000，tag=testTag）
- **能力依赖**：@kit.AbilityKit（UIAbility/Want/abilityAccessCtrl/common）、@kit.ArkUI（window）
- **语音能力**：@kit.CoreSpeechKit（speechRecognizer 语音识别 + textToSpeech 语音合成，端侧离线）、@kit.AudioKit（AudioCapturer 麦克风录音）
- **测试框架**：@ohos/hypium 1.0.25、@ohos/hamock 1.0.0（devDependencies）
- **跨平台层**：ArkUI-X（local.properties 指向 D:/ArkUI-X/Sdk）

## 2.1 业务架构（语音计算器，2026-09-07 起）

```
用户
 ├─ 点击按键 ──────────→ CalculatorEngine（状态机+求值）→ 显示区
 └─ 说出算式（麦克风）→ SpeechService.ASR（speechRecognizer）
                            │ 中文文本
                            ▼
                    VoiceCommand（中文数字→表达式："十二加八"→12+8）
                            │ 表达式/动作
                            ▼
                    CalculatorEngine（求值）→ 显示区 → SpeechService.TTS（结果中文朗读）
```

- 纯逻辑层（`ets/model/`，不依赖鸿蒙 API，可单测）：ChineseNumber / CalculatorEngine / VoiceCommand
- 语音层（`ets/service/`）：SpeechService（ASR + TTS + 录音）
- 无障碍设计：语音输入替代按键、结果语音播报

## 4. 模块架构（entry）

- **应用模型**：Stage 模型（apiType: stageMode）。
- **Ability**：`EntryAbility`（UIAbility），注册于 module.json5 `abilities`，`exported=true`，含 Home 入口 skills；生命周期回调 onCreate/onDestroy/onWindowStageCreate/onWindowStageDestroy/onForeground/onBackground 均有 hilog 日志埋点；onWindowStageCreate 中申请 `ohos.permission.MICROPHONE`（运行时权限）。
- **页面路由**：`main_pages.json` 注册首页 `pages/Index`；`onWindowStageCreate` 中 `loadContent('pages/Index')` 加载。
- **首页 Index.ets（语音计算器）**：`@Entry @Component`，持有 `CalculatorEngine` 与 `SpeechService`；布局 = 顶栏 + 显示区（表达式行/结果行）+ 语音状态提示 + 5×4 按键网格（C/⌫/÷/× … 0/. /🎤语音键，语音键跨 2 列）；等号计算后自动中文播报结果。
- **权限声明**：module.json5 `requestPermissions` 含 `ohos.permission.MICROPHONE`（usedScene=inuse，reason=$string:mic_reason）。
- **启动窗口**：startWindowIcon = startIcon，startWindowBackground = #FFFFFF。

## 8. 跨平台层（ArkUI-X）

- 本地 SDK 路径：`D:/ArkUI-X/Sdk`（local.properties，本机配置不入库）。
- `.arkui-x/android`：Gradle 壳工程（settings.gradle、app 模块、gradle wrapper），Java 包名 com.example.myapplication，可出 Android APK。
- `.arkui-x/ios`：Xcode 壳工程（app.xcodeproj、Assets.xcassets），可出 iOS 包。
- 说明：该目录由工具链自动生成，一般无需手改；编译入口统一走 hvigor（AppTasksForArkUIX / HapTasks）。
